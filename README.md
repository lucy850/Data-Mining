# Student Performance Analysis Using Data Mining

## Overview

This project analyzes student performance data using data mining
techniques to identify patterns and group students based on their
academic performance and learning-related factors.

## Dataset

The dataset contains 395 student records with selected features:

- Study Time
- Free Time
- Absences
- G1
- G2
- G3

## Objectives

- Perform data selection and data cleaning
- Prepare the dataset for clustering
- Apply data transformation
- Determine the optimal number of clusters
- Apply K-Means clustering
- Compare the results with Hierarchical Clustering
- Analyze the characteristics of each cluster

## Data Mining Process

1. Data Selection
2. Data Cleaning
3. Data Transformation
4. Exploratory Data Analysis
5. K-Means Clustering
6. Hierarchical Clustering
7. Cluster Evaluation
8. Result Interpretation

## Results

The clustering analysis identifies groups of students based on
study habits, absences, and academic performance.
